# Scripts

Небольшие Python-скрипты для массовой обработки изображений.

Для `resize.py` и `resize_rename.py` требуется Pillow:

```bash
pip install Pillow
```

## rename_files.py

Массово переименовывает файлы по шаблону из `rename_template.txt`.

Пример шаблона:

```text
name_[001].jpg
```

Результат:

```text
name_001.jpg
name_002.jpg
name_003.jpg
...
```

Число в `[]` задаёт начальный номер и количество цифр.

Скрипт правильно сортирует исходные файлы по числам (`1, 2, 11, 101`, а не `1, 101, 11, 2`).

Запуск:

```bash
python rename_files.py
```

Перед переименованием показывает список изменений и просит подтверждение.

---

## resize.py

Массово изменяет ширину изображений с сохранением пропорций и конвертирует их в WebP.

Ширина задаётся в `data.txt`, например:

```text
800
```

Результат сохраняется в папку:

```text
img_800
```

Исходные имена файлов сохраняются.

Поддерживаются JPG, JPEG, PNG, BMP, TIFF и WebP.

Запуск:

```bash
python resize.py
```

---

## resize_rename.py

То же, что `resize.py`, но дополнительно переименовывает готовые изображения:

```text
1.webp
2.webp
3.webp
...
```

Ширина также задаётся в `data.txt`.

Результат сохраняется в `img_<ширина>`.

Запуск:

```bash
python resize_rename.py
```

---

## Служебные файлы

`data.txt` — ширина изображения в пикселях для `resize.py` и `resize_rename.py`.

`rename_template.txt` — шаблон имени для `rename_files.py`, например:

```text
name_[001].jpg
```
